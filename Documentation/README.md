# How the bot works

## Hivemind

The way of working is an hivemind where there is an central controller but the workers control also themself.
The workers will execute jobs based on their capacity.

## Rooms

All rooms will get job sites, where dedicated tasks can be executed that are part of an job.
Each room will get overseen by some system classes that monitor it needs and acts accordingly
